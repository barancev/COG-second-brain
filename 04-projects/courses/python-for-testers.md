# Программирование на Python для тестировщиков

- **Формат:** онлайн, 10 занятий (15 часов теории) + практические задания; лекции по пятницам до 12:00 МСК, видео в любое время, консультации в групповом чате.
- **Доступ к материалам:** 1 год после окончания.
- **Стоимость:** 19 500 ₽ (физлица), 24 500 ₽ (юрлица; скидка 15% от 3 участников; постоплата +25%).
- **Аудитория:** тестировщики со знанием школьной информатики и программирования на школьном уровне на любом языке.
- **Результат:** несколько проектов в едином стиле — автотесты веб-приложений (Selenium), Windows-приложений, работы с БД, сетевых интерфейсов (почта, HTTP, веб-сервисы), тесты на Gherkin.
- **Стек:** Python 3, PyCharm, py.test (переход с unittest), Selenium WebDriver, GitHub, SQL/JSON/Excel, pywinauto (Windows UI), FTP/Telnet/POP3/SOAP, BDD, Allure, CI (Jenkins), Robot Framework.
- **Учебные приложения:** адресная книга (модули 1–8, 10) и баг-трекер Mantis (модуль 9).
- **Сертификат:** выдаётся при успешной сдаче заданий.
- **Страница:** https://software-testing.ru/edu/3/233-python

## Программа

Лекции идут списком, задания выделены жирным. `*` у задания — необязательное домашнее задание.

### 1. Подготовка инфраструктуры и создание первых работающих тестов

**Подготовка инфраструктуры**
- Установка Python
- Установка среды разработки PyCharm
- Менеджер пакетов pip и установка дополнительных библиотек

**Основы языка Python**
- Переменные и значения переменных; типы данных
- Выражения
- Функции
- Работа с библиотеками, конструкция import
- Классы и объекты
- «Самодельные» классы
- Модули и пакеты

**А теперь, наконец, программирование для тестировщиков :)**
- Создание проекта на GitHub
- Создание первого теста
- **Задание №1:** подготовить инфраструктуру и создать первый работающий тест
- Основные элементы структуры кода
- Создание вспомогательных методов, повышение «читаемости» кода
- Передача параметров в методы
- Шаблон проектирования Parameter Object
- **Задание №2:** создать вспомогательные методы и классы
- **Задание №3:** сделать всё то же самое, но для контактов

### 2. Двухуровневая архитектура тестового набора
- Немного теории про стек автотестирования, про веб-драйвер, и небольшое улучшение читаемости тестов
- «Фикстура»: общий код инициализации и завершения
- **Задание №4:** перевести тесты с unittest на py.test и реализовать фикстуры
- Декомпозиция кода, классы-помощники
- **Задание №5:** реализовать двухуровневую архитектуру тестов
- Делаем новые тесты без рекордера
- **Задание №6:** сделать фикстуру общей для всех тестов
- **Задание №7:** сделать все тесты создания, удаления, модификации для групп и контактов

### 3. Управление потоком выполнения кода (конструкция if-then-else)
- Немного теории про ветвление (конструкция if-then-else)
- Оптимизация ввода данных в формы
- Повышаем «интеллектуальность» фикстуры: валидация фикстуры перед каждым тестом
- Повышаем «интеллектуальность» функций login и logout: проверка текущего состояния сессии
- **Задание №8:** реализовать проверку валидности фикстуры и проверку состояния сессии
- Повышаем «интеллектуальность» тестов: обеспечение выполнения предусловий
- **Задание №9:** обеспечить выполнение предусловий в тестах для удаления и модификации групп и контактов
- Повышаем «интеллектуальность» навигации: избавляемся от лишних переходов
- **Задание №10:** оптимизировать переходы между страницами

### 4. Коллекции и циклы

**Коллекции, циклы и элементы функционального программирования**
- Последовательности: списки, кортежи и диапазоны
- Проверка равенства объектов и списков
- Сортировка списков
- Лирическое отступление: вывод объектов на консоль в удобном виде
- Лямбда-выражения
- Циклы и конструкция list comprehension
- Элементы функционального программирования: map и filter

**Продолжаем разрабатывать тесты**
- Загружаем информацию из тестируемого приложения в виде списков
- Проверка равенства объектов и списков
- Сортировка списков перед сравнением
- **Задание №11:** реализовать проверки в виде сравнения списков
- Ускорение массовых операций: кеширование и хеширование
- **Задание №12:** реализовать кеширование при загрузке списков групп и контактов
- Добавляем немного случайности в тесты
- **Задание №13:** доработать тесты так, чтобы в них удалялся или модифицировался случайно выбранный элемент

### 5. Строки

**Немного теории про работу со строками**
- Основные операции над строками: склейка и разрезание
- Основы работы с регулярными выражениями
- Практический пример: генерация случайной строки

**Продолжаем разрабатывать тесты**
- Улучшение функции чтения информации о пользователе из тестируемого приложения
- Режем строки на части: делаем тесты для проверки телефонов
- Клеим строки из частей: прямые и обратные проверки
- **Задание №14:** реализовать проверки для всех полей контакта на главной странице
- Параметризация тестов. Data Driven Testing
- **Задание №15:** параметризовать тесты для создания групп и контактов
- Передача параметров в тесты из командной строки при запуске
- **Задание №16:** реализовать опции командной строки для указания типа браузера и адреса тестируемого приложения

### 6. Работа с файлами

**Немного теории про работу с файлами и директориями**
- Словари, или ассоциативные массивы (это ещё не про файлы :) )
- Работа с объектами файловой системы — файлами и директориями
- Чтение данных из файлов и запись данных в файлы
- Чтение и запись файлов в формате JSON
- Обработка исключений (это уже опять не про файлы :) )
- Конструкция with и автоматическая «зачистка»

**Продолжаем разрабатывать тесты**
- Конфигурационный файл для описания тестируемого приложения
- Автоматическое определение путей к файлам относительно директории проекта
- **Задание №17:** реализовать загрузку информации о тестируемом приложении из конфигурационного файла
- Отделение тестовых данных от сценариев (DDT продолжается)
- Генерация тестовых данных в формате JSON
- Ещё один способ параметризации тестов: динамическая генерация тестов
- Загрузка тестовых данных из файлов в формате JSON
- **Задание №18:** реализовать генераторы тестовых данных
- **Задание №19:** реализовать загрузку тестовых данных из файлов

### 7. Работа с базами данных
- Драйвер базы данных, выполнение простых SQL-запросов
- Фикстура для взаимодействия с базой данных
- Загрузка информации из базы данных в виде объектов
- Переделываем тесты: проверяем данные, загруженные из базы данных
- Отключаемые проверки пользовательского интерфейса
- Ограничения или условия отбора загружаемых данных
- ORM — Object Relational Mapping
- Отношения между объектами
- **Задание №20:** переделать тесты, чтобы сравнивались данные, загруженные из БД
- **Задание №21:** переделать тесты для проверки информации о контактах на главной странице
- **Задание №22:** реализовать тесты для добавления контакта в группу и удаления контакта из группы

### 8. Автоматизация Windows UI
- Мини-обзор инструментов для работы с GUI
- Pywinauto: запуск и останов тестируемого приложения
- Pywinauto: взаимодействие с элементами управления
- **Задание №23*:** реализовать тесты для создания и удаления групп в адресной книге
- Сохранение данных в формате Excel
- **Задание №24*:** реализовать генерацию и чтение тестовых данных в формате Excel

### 9. Сетевое программирование (протоколы прикладного уровня)
- Новое учебное приложение: баг-трекер Mantis
- **Задание №25:** реализовать тесты для добавления и удаления проектов в Mantis
- File Transfer Protocol (FTP)
- Удалённое управление по протоколу Telnet
- Получение почты по протоколу POP3
- Simple Object Access Protocol (SOAP)
- **Задание №26:** реализовать проверки списков проектов через SOAP

### 10. Разные стили написания тестов и отчёты о результатах выполнения
- Behavior Driven Testing (BDD)
- **Задание №27*:** реализовать тесты в стиле BDD
- Continuous Integration (CI): запуск тестов
- Continuous Integration (CI): генерация отчётов
- **Задание №28:** настроить запуск тестов на сервере непрерывной интеграции
- Allure Report Generator
- **Задание №29*:** реализовать генерацию отчётов при помощи Allure
- Robot Framework
- **Задание №30*:** реализовать тесты с использованием Robot Framework
