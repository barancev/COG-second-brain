# Программирование на TypeScript для тестировщиков

🚧 **В разработке** через ultragoal `ts-for-testers` ([[04-projects/ts-for-testers/STATUS|статус]] · [[04-projects/ts-for-testers/spec|контракт]]).

## Позиционирование (черновик)
- **Угол:** веб/E2E на TypeScript. Типобезопасные автотесты фронтенда: Playwright + TypeScript, Page Object Model, фикстуры. Самое естественное применение TS у тестировщиков.
- **Аудитория:** тестировщики со знанием школьной информатики и программирования на школьном уровне на любом языке (как в других курсах).
- **Результат (план):** студент пишет поддерживаемые типобезопасные E2E-автотесты веб-приложения с правильной архитектурой (POM, фикстуры), умеет работать с данными, сетью/API и запускать тесты в CI с отчётами.
- **Стек (черновик, фиксируется в P2):** TypeScript, Playwright, Node.js, тест-раннер (Playwright Test или Vitest — решение в P1/P2), CI (GitHub Actions/Jenkins), Allure Report.
- **Учебное приложение (SUT):** выбирается в P2 — открытый фронтенд с формами, списками, аутентификацией и, желательно, API.
- **Формат/длительность/цена:** по образцу других курсов (онлайн, еженедельные лекции + задания); конкретные цифры — на этапе готовности (P6).

## Программа
_Будет разработана в фазе P1. Дуга: основы TypeScript → тест-раннер → Playwright/POM/фикстуры → данные и файлы → сеть/API → CI и отчёты._
