# Разработка и доработка курсов

## What is this project?
Создание новых курсов по тестированию и развитие существующих: программа, материалы, задания, обратная связь студентов.

## Курсы

| Курс | Статус | Описание |
|------|--------|----------|
| Программирование на Python для тестировщиков | активный | Язык Python и вспомогательные библиотеки для автотестов приложений разных типов; шаблоны проектирования для организации кода. |
| Программирование на Java для тестировщиков | активный | Язык Java и вспомогательные библиотеки для автотестов приложений разных типов; шаблоны проектирования для организации кода. |
| Программирование на C# для тестировщиков | активный | Язык C# и вспомогательные библиотеки для автотестов приложений разных типов; шаблоны проектирования для организации кода. |
| Тестирование веб-приложений 2.0 | активный | Особенности тестирования веб-приложений (HTML, CSS, JavaScript); специфика применения техник тест-дизайна. |
| Тестирование производительности: JMeter 5 | активный | Инструменты мониторинга характеристик производительности и генерации нагрузки для веб-приложений. |
