# Тестирование веб-приложений 2.0

- **Формат:** онлайн, 9 занятий (7–9 часов теории) + практические задания; лекции дважды в неделю (вторник и пятница до 12:00 МСК), консультации в групповом чате.
- **Доступ к материалам:** 1 год после окончания.
- **Стоимость:** 12 000 ₽ (физлица), 15 500 ₽ (юрлица; скидка 15% от 3 участников).
- **Аудитория:** специалисты, владеющие техниками тест-дизайна. Новичкам рекомендуется сначала «Практикум по тест-дизайну» или «Школа для начинающих тестировщиков».
- **Результат:** проектирование тестов веб-приложений; функциональное и нефункциональное тестирование; анализ ссылок и стандартов; поиск уязвимостей; оценка производительности и удобства использования.
- **Стек:** HTML/CSS/JavaScript, HTTP/DNS/IPv4/IPv6, Developer Tools, AJAX/REST/WebSocket, SQL, перехват трафика, инструменты анализа производительности и безопасности.
- **Сертификат:** выдаётся при успешном завершении.
- **Страница:** https://software-testing.ru/edu/3/189-web

## Программа

Лекции идут списком, задания выделены жирным.

### 1. Основы
- 1.1. Общая теория: что такое тестирование и что такое программа?
- 1.2. Что нужно тестировать?
- 1.3. Структура программы и её интерфейсы
- 1.4. Внутреннее устройство браузера
- 1.5. HyperText Markup Language (HTML)
- 1.6. Тестирование разметки
- 1.7. Тестирование текстового содержимого страниц
- 1.8. Тестирование ссылок
- 1.9. Тестирование локализации
- **Задание 1:** проверьте соответствие страницы стандарту HTML

### 2. Клиент и сервер
- 2.1. Клиент-серверная архитектура
- 2.2. HyperText Transfer Protocol (HTTP)
- 2.3. Перехват запросов и ответов
- 2.4. HTTP, продолжение
- 2.5. Протоколирование запросов и ответов на сервере
- 2.6. User-Agent: браузеры и боты
- 2.7. Отправка на сервер поддельных запросов
- 2.8. Адреса ресурсов. Domain Name Service (DNS)
- **Задание 2:** проанализируйте трафик между браузером и сервером

### 3. Динамическая генерация страниц
- 3.1. Что происходит с запросом на сервере
- 3.2. Генерация полезной нагрузки
- 3.3. Источники данных (файлы, база данных)
- 3.4. Кеширование данных на стороне сервера
- 3.5. Многоуровневая архитектура
- 3.6. Аутентификация и авторизация
- 3.7. Тестирование прав доступа
- 3.8. Тестирование производительности серверной части
- **Задание 3:** сделайте тесты для проверки прав доступа
- **Задание 4:** сделайте тест для оценки производительности

### 4. Формы: получение данных от пользователя
- 4.1. Ввод данных в формы
- 4.2. Типы запросов GET и POST
- 4.3. Неявные параметры запроса
- 4.4. Функциональное тестирование
- 4.5. Автоматизация функционального тестирования
- 4.6. Тестирование производительности
- 4.7. Тестирование защищённости
- **Задание 5:** сделайте тесты для проверки валидации данных на сервере
- **Задание 6:** автоматизируйте небольшой сценарий

### 5. Вёрстка страниц (CSS)
- 5.1. Cascading Style Sheets (CSS)
- 5.2. Cascading Style Sheets (CSS), продолжение
- 5.3. Автоматическая проверка CSS
- 5.4. Тестирование вёрстки (layout)
- 5.5. Адаптивная вёрстка
- 5.6. Семантическая вёрстка
- **Задание 7:** проверьте сайт на соответствие стандарту CSS
- **Задание 8:** проверьте адаптивность вёрстки на сайте

### 6. JavaScript и интерактивность
- 6.1. JavaScript
- 6.2. Анимация без JavaScript
- 6.3. Document Object Model (DOM)
- 6.4. Валидация данных в формах
- 6.5. Асинхронные запросы (AJAX)
- 6.6. Одностраничники (Single Page Application, SPA)
- 6.7. REST API
- **Задание 9:** проанализируйте работу приложения с AJAX
- **Задание 10:** реализуйте сценарий взаимодействия через REST API

### 7. Картинки и клиентская производительность
- 7.1. Клиентская производительность
- 7.2. Инструменты для оценки клиентской производительности
- 7.3. Оптимизация клиентской производительности
- **Задание 11:** проанализируйте клиентскую производительность

### 8. Подробнее про тестирование
- 8.1. Тестирование функциональности
- 8.2. Тестирование производительности
- 8.3. Тестирование удобства использования и доступности
- **Задание 12:** проанализируйте доступность страницы

### 9. Не совсем про тестирование
- 9.1. Мониторинг
- 9.2. Сплит-тестирование
- 9.3. Оптимизация для поисковиков и социальных сетей
