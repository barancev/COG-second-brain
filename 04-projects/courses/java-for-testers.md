# Программирование на Java для тестировщиков

- **Формат:** онлайн, 10 занятий (15 часов теории) + практические задания; лекции по пятницам, видео в любое время.
- **Доступ к материалам:** 1 год после окончания.
- **Стоимость:** 20 500 ₽ (физлица), 26 500 ₽ (юрлица; скидка 15% от 3 участников).
- **Аудитория:** тестировщики со знанием школьной информатики и программирования на школьном уровне.
- **Результат:** автоматизированные тесты для веб-приложений; архитектурные каркасы и шаблоны проектирования для организации кода автотестов.
- **Стек:** Java 17, IntelliJ IDEA, JUnit 5, Gradle, Selenium WebDriver 4, Selenium Server, Jackson, Hibernate 6, OkHttp3, Angus Mail, James 3, Swagger, Allure Report, Jenkins.
- **Учебные приложения:** адресная книга (модули 2–7) и баг-трекер MantisBT с почтовым сервером James (модули 8–9).
- **Сертификат:** выдаётся при успешной сдаче заданий.
- **Страница:** https://software-testing.ru/edu/3/1-java-for-testers

### К исправлению
- Лекция 0.2 «Среда разработки IntelliJ IDEA»: упомянуть альтернативные IDE на том же движке — OpenIDE, GigaIDE.
- Лекция 0.5 «Сборщик Gradle»: информация о проекте из нескольких модулей устарела. С Gradle 9 появились [multi-project builds](https://docs.gradle.org/current/userguide/multi_project_builds.html) — переписать на этот способ организации многомодульного проекта.
- После лекции 1.7 «Фреймворк для запуска тестов JUnit» добавить лекцию про аннотации в Java: что означает `@Test` возле тестов и как аннотации обрабатываются при компиляции и выполнении.
- Лекция 2.5 «Тестирование веб-приложений через GUI»: для первоначальной записи сценария используется Selenium IDE, но он больше не ставится в Chrome и имеет проблемы в Firefox. Найти альтернативу и переделать лекцию.
- Лекция 3.2 «Модельные классы для сущностей предметной области»: сейчас для получения копии record-объекта с изменёнными свойствами вручную пишется несколько with-методов — трудоёмко. Показать библиотеку [record-builder](https://github.com/Randgalt/record-builder), которая генерирует такие методы через процессор аннотаций (связано с планируемой лекцией про аннотации после 1.7). Упомянуть [JEP 468 (Derived Record Creation)](https://openjdk.org/jeps/468) — в будущем, возможно, позволит создавать with-методы без дополнительных библиотек.
- Лекции 9.x про почтовый сервис DeveloperMail.com (сейчас скрыты): сервис больше не работает. Подобрать замену — сервис с Remote API для создания временных почтовых адресов и получения почты — и переписать лекции.
- Gradle-плагин для генерации кода из Swagger [gradle-swagger-generator-plugin](https://github.com/int128/gradle-swagger-generator-plugin) больше не поддерживается и, возможно, несовместим с последними версиями Gradle. Заменить на другой, например [openapi-generator](https://github.com/OpenAPITools/openapi-generator).
- Описание на сайте обещает тестирование Windows-приложений (GUI), но в актуальной программе такого модуля нет (GUI — только веб, адресная книга). Решить: убрать обещание с сайта или добавить модуль. _[Проверено 2026-10-15 против software-testing.ru/edu/3/1-java-for-testers]_
