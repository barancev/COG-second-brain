# SPEC: Курс «Программирование на TypeScript для тестировщиков»

> Lane: `full` · Goal folder: `04-projects/ts-for-testers/` · Date: 2026-10-16

## North-star
Готовый к запуску на software-testing.ru курс «Программирование на TypeScript для тестировщиков»: полная программа, написанные лекции и домашние задания по всем модулям, рабочее учебное приложение и описание курса. Угол — веб/E2E на TypeScript (Playwright): типобезопасные автотесты фронтенда, Page Object Model, фикстуры. Аудитория — как в других курсах: тестировщики со знанием школьной информатики и программирования на школьном уровне на любом языке.

## Non-goals
- Не переписываем существующие курсы (Java/Python/C#) и не дублируем их дугу один в один.
- Не разрабатываем инфраструктуру продаж/LMS — это проект `stqa-infrastructure`.
- Не покрываем в курсе юнит-тестирование библиотек на TS как основную тему (фокус — E2E/веб и прикладные интерфейсы).
- Не записываем видео на этом этапе (готовность = материалы и задания; запись — отдельное решение).

## Risks and open questions
- **Объём контента большой.** Митигация: модули разбиты на фазы P3–P5; точный состав модулей фиксируется в P1 и может изменить границы фаз.
- **Выбор учебного приложения (SUT).** В Java-курсе это адресная книга + Mantis. Для веб/E2E нужен открытый фронтенд с формами, списками, аутентификацией, желательно с API. Решение — в P2 (с опорой на программу из P1).
- **Актуальность стека.** Playwright развивается быстро (1.64 на октябрь 2026). Фиксировать версии в P2 и отмечать в материалах, чтобы курс не устарел.
- **Тест-раннер:** Playwright Test vs Vitest/Jest. Решение в P1/P2.
- **Инструмент вместо Playwright:** рассмотреть WebdriverIO как альтернативу Playwright для E2E-угла, в том числе его новые AI-возможности (WebdriverIO v10: `wdio session`, `browser.act()` — агент проходит сценарий и экспортирует шаги как код). См. [[01-daily/briefs/daily-brief-2026-10-16|daily brief 16.10]]. Решение по инструменту — в P1/P2.
