# Сайт для продажи курсов

## What is this project?
Сайт, через который продаются курсы по тестированию: https://www.software-testing.ru/edu/ . Это раздел информационного сайта software-testing.ru, посвящённого тестированию. Сайт работает давно и разрабатывается самостоятельно.

## Current Status
- Сейчас сайт работает на CMS Joomla.
- План: переписать раздел на генераторе статических сайтов Astro.
- Данные о курсах сайт будет получать из [[04-projects/student-registry/PROJECT-OVERVIEW|системы регистрации и учёта студентов]].
- Цель: один источник информации о курсах вместо двух.

*Название генератора записано как Astro (в исходном сообщении "astra"); уточнить, если это другой инструмент.*
